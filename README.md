# Portfolio Optimization Using Python

This is my first finance data analytics project, where I analyze my personal Questrade investment portfolio and apply modern portfolio theory concepts using Python.

The objective of this project is to evaluate portfolio performance, measure risk, understand diversification benefits, and determine whether an optimized portfolio allocation can improve the risk-adjusted return.

## Methodology

The project follows these steps:

1. **Calculate Asset Returns**
   - Collect historical price data
   - Calculate daily/monthly returns for each asset

2. **Measure Portfolio Risk**
   - Calculate volatility using standard deviation
   - Annualize risk measures

3. **Analyze Correlation**
   - Examine relationships between assets
   - Understand diversification effects

4. **Calculate Covariance Matrix**
   - Measure how asset returns move together
   - Use covariance as an input for portfolio optimization

5. **Generate Efficient Frontier**
   - Create portfolios with different risk-return combinations
   - Visualize optimal portfolio opportunities

6. **Calculate Sharpe Ratio**
   - Evaluate risk-adjusted performance
   - Compare portfolio returns relative to risk taken

7. **Find Optimal Portfolio Allocation**
   - Identify the portfolio with the highest Sharpe ratio
   - Determine asset weights that maximize risk-adjusted returns
